- AIバブルはすでに終わっているか、終わりつつあると言えるため、投資家は過度な楽観を控えるべき。
- 半導体・メモリー株だけでなく、データセンターの建設・発電設備などのAIインフラ関連株も大きな調整局面に入っている。
- 資金調達難や長期金利の高止まり、信用与信の縮小などが重なり、景気の逆風となる可能性がある。
- 次の10年は国際分散投資の時代になり、欧州株や新興国株が二桁の比較的高いたかいパフォーマンスを予想する。

# 5. リスクや注意点として話されていたこと
- ネオクラウド企業がIPO撤回・延期や資金不足、住民の反対運動により、データセンターの建設計画が遅延・延期している。
- 金利が5%を超え、エヌビディア新経営陣の下で循環取引や信用供与の規模が縮小する可能性があり、資金調達が難しくなる。
- AI設備投資の拡大がGDPを押し上げても、それが将来の利益として回収できるかは別問題である。
- 株式市場の参加者は1年〜1年半先の業績を織り込むため、2027年が強気でも2028年以降の景気が弱ければ株価は上がりづらくなる。
- 雇用への影響は2028年〜2029年頃に拡大する可能性がある。

# 6. 視聴者への具体的な提案
- AIインフラ投資の規模縮小、長期金利の高止まり、雇用への悪影響が予想以上に大きくなった場合の市場の急変に注意する。
- 株式のエクスポージャーは一気に引き上げるのではなく、段階的に引き上げていくことが望ましい。
